# Asset pipeline

Every model in `client/assets/models/*.glb` is generated by a deterministic Blender script in this folder
(fixed seeds, no randomness from time/environment). Re-run a script and the asset is rebuilt.

```bash
blender -b -P tools/assets/rifle.py          # one asset (+ preview PNGs in docs/previews/)
blender -b -P tools/assets/build_all.py      # everything
python tools/assets/build_all.py             # same, using the `bpy` wheel:  pip install bpy
python tools/assets/rifle.py --no-preview    # skip the Cycles preview renders (fast)
```

| Script | Output |
|--------|--------|
| `map_kit.py` | `map.glb` — one prop per collision box in `client/shared/map.json` (so visuals == collision) |
| `rifle.py` | `rifle.glb`, `rifle_fp.glb` (first person, with gloved hands) |
| `pistol.py` | `pistol.glb`, `pistol_fp.glb` |
| `knife.py` | `knife.glb`, `knife_fp.glb` |
| `character.py` | `character_a.glb`, `character_b.glb` (team colours; armature + animations) |

Shared code: `common.py` (bmesh builders, materials, glTF export, preview renders), `texgen.py` (numpy procedural
textures: concrete, wood, corrugated metal, burlap, fabric, nylon, polymer, gunmetal …; tileable; JPEG in the glb),
`weapon_parts.py` (generic fictional weapon designs).

Texture note: textures are generated with numpy and written into Blender images (not baked from Blender shader
nodes), then embedded as JPEG (q85) in each glb. Blender 5.x via the PyPI `bpy` wheel was used to build the shipped files.
